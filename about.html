THE PROJECT

Our Story

We are New Gen Group — a team of Computer Science students enrolled in Introduction to Cloud Computing. This website is our group's unit project, created collaboratively for the first time.

Our focus throughout this project was on four pillars: Functionality, Design, User-Friendliness, and Efficiency. We built this as a fully static website — HTML, CSS, and JavaScript — with no backend or database required.

The site was designed, developed, and deployed through GitHub Pages, giving us hands-on experience with real-world cloud hosting and version control collaboration.
